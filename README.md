# qa_python

`add_new_book` добавление 1 и 2 книг, пустой жанр, длина 1/39/40, пустое имя, 41 и 100 символов, дубликат, дубликат не сбрасывает жанр  
`set_book_genre` все 5 валидных жанров, смена жанра, жанр не из списка, другой регистр, пустой жанр, книги нет в словаре  
`get_book_genre` жанр существующей книги, `None` для неизвестной книги  
`get_books_with_specific_genre` список книг одного жанра, нет книг этого жанра, невалидный жанр, пустой словарь  
`get_books_genre` словарь с книгой и жанром  
`get_books_for_children` только жанры без возрастного рейтинга, книга без жанра, «Ужасы»/«Детективы», пустой словарь  
`add_book_in_favorites` добавление одной и двух книг, повторное добавление, книги нет в словаре  
`delete_book_from_favorites` удаление из избранного, удаление отсутствующей книги, книга остаётся в `books_genre`  
`get_list_of_favorites_books` список добавленных книг, пустой список по умолчанию
